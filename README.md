## อธิบายไฟล์ข้อมูลทีละคอลัมน์ (เพราะเป็นจุดที่งงกันบ่อย)

### `bookings-fact.csv` — ไฟล์หลัก มี 1 แถวต่อ "1 เดือน x 1 เส้นทาง" (12 เดือน × 5 เส้นทาง = 60 แถว)

| คอลัมน์ | ความหมาย | ตัวอย่าง |
|---|---|---|
| `month` | เดือนที่ของแถวนี้ (YYYY-MM) | `2026-03` |
| `route_code` | รหัสเส้นทางภายใน ใช้เชื่อมข้อมูล ไม่ต้องอ่าน | `BKK-HKG` |
| `route_label` | ชื่อเส้นทางแบบอ่านง่าย | `BKK → HKG` |
| `airline` | สายการบินของเส้นทางนี้ | `Thai Airways` |
| `bookings` | ตั๋วที่ออกสำเร็จทั้งหมด = `converted_to_booking` + `direct_bookings` | `111` |
| `direct_bookings` | ตั๋วที่ลูกค้าซื้อทันทีโดยไม่ผ่านการตรึงราคา | `31` |
| `price_freezes_created` | จำนวนครั้งที่มีคนกด "ตรึงราคา" (ยังไม่ใช่ตั๋วที่ออกจริง) | `123` |
| `converted_to_booking` | ในจำนวนที่ตรึงราคาไว้ มีกี่ครั้งที่กลับมาจ่ายจนออกตั๋วจริง | `80` |
| `avg_ticket_price_thb` | ราคาตั๋วเฉลี่ยของเส้นทางนั้นในเดือนนั้น (บาท) | `2155` |
| `ticket_revenue_thb` | รายได้จากค่าตั๋ว = `bookings × avg_ticket_price_thb` (บาท) | `239205` |
| `freeze_fee_revenue_thb` | รายได้จากค่าธรรมเนียมตรึงราคา (เฉลี่ย 6% ของราคาตั๋ว × จำนวนครั้งที่ตรึง) (บาท) | `15904` |

**หนึ่งแถวอ่านว่า:** "เดือนนี้ เส้นทางนี้ มีคนตรึงราคาไว้กี่ครั้ง ในนั้นกี่ครั้งที่ซื้อจริง มีคนซื้อตรงอีกกี่ใบ ได้รายได้เท่าไหร่"
(ตัวอย่างในตารางคือแถวแรกของไฟล์จริง: ต.ค. 2025, BKK → CNX)

### `search-funnel.csv` — 1 แถวต่อ 1 เดือน (ไม่แยกตามเส้นทาง เพราะคนค้นหายังไม่เลือกเส้นทางตอนเข้าเว็บครั้งแรก)

| คอลัมน์ | ความหมาย |
|---|---|
| `month` | เดือน (YYYY-MM) |
| `searches` | จำนวนครั้งที่มีคนค้นหาเที่ยวบิน (บนสุดของ funnel) |
| `price_freezes_created` | จำนวนที่ตรึงราคา (ตัวเลขเดียวกับผลรวมใน bookings-fact.csv ของเดือนนั้น) |
| `converted_to_booking` | จำนวนที่ออกตั๋วจริง (ตัวเลขเดียวกับผลรวมใน bookings-fact.csv ของเดือนนั้น) |

**ทำไมต้องแยกเป็น 2 ไฟล์:** `bookings-fact.csv` ตอบคำถาม "แต่ละเส้นทางทำเงินได้เท่าไหร่" ส่วน `search-funnel.csv` ตอบคำถาม "คนร่วงหายไปตรงขั้นตอนไหนของ funnel" — เป็นคนละมุมมอง รวมในไฟล์เดียวจะทำให้ต้องนับซ้ำ (double count) เวลา sum ยอดรวม

> ⚠️ **ตัวเลขทั้งหมดเป็นข้อมูลประมาณการ (illustrative)** สำหรับใช้นำเสนอไอเดียธุรกิจ ไม่ใช่ยอดขายจริง
> สร้างจากสมมติฐานที่อิงกับราคาตั๋วจริงของแต่ละเส้นทางและโครงสร้างค่าธรรมเนียม 5–8% ที่ระบบ FreezeFly ใช้งานจริง

## Dashboard ทำอะไรได้บ้าง

**เล่าเรื่องจากบนลงล่าง:** ปัญหาและขนาดตลาด → โซลูชัน 3 ขั้นตอน → หลักฐานจากข้อมูล → ทดลองสมมติฐาน → โมเดลรายได้และก้าวต่อไป

**ลูกเล่นที่ใช้ได้จริง:**
- **ตัวกรอง** ช่วงเวลา (3/6/12 เดือน) และเส้นทาง — ทุกกราฟ KPI insight และตารางคำนวณใหม่ทันที
- **ชี้เมาส์บนกราฟ** เพื่อดูตัวเลขของเดือน/เส้นทาง/ขั้นตอนนั้น (บนมือถือใช้แตะแทน)
- **คลิกชิ้นโดนัท แท่งเส้นทาง หรือชื่อเส้นทาง** เพื่อดูเฉพาะเส้นทางนั้น คลิกซ้ำเพื่อกลับมาดูทั้งหมด
- **KPI การ์ด** ตัวเลขนับขึ้น มีกราฟเส้นจิ๋วแสดงแนวโน้ม และ % เทียบกับช่วงเวลาก่อนหน้า
- **Insight อัตโนมัติ 3 ข้อ** (เส้นทางที่ทำเงิน, แนวโน้ม, จุดที่ลูกค้าหลุดมากที่สุด) เปลี่ยนตามตัวกรอง
- **What-if:** ลากแถบเลื่อนปรับค่าธรรมเนียม (2–12%) และความไวต่อราคา แล้วดูว่ารายได้ค่าธรรมเนียมเปลี่ยนอย่างไร พร้อมจุดที่รายได้สูงสุด
  สมมติฐาน: ขึ้นค่าธรรมเนียม 1% → คนตรึงราคาลดลงตาม % ที่ตั้งไว้ (ค่าเริ่มต้น 8%) เป็นโมเดลอย่างง่ายเพื่อประกอบการตัดสินใจ ไม่ใช่การพยากรณ์จริง
- **ตารางข้อมูลดิบ** ท้ายหน้า แถวเดียวกับใน CSV กรองตามตัวกรองด้านบน

กราฟทั้งหมดวาดด้วย Canvas ในไฟล์เดียว **ไม่ต้องใช้อินเทอร์เน็ต** (ถ้าไม่มีเน็ต แค่ฟอนต์ Kanit จะเปลี่ยนเป็นฟอนต์สำรองของเครื่อง)
ทดสอบแล้วว่าตัวเลขทุกตัวตรงกับข้อมูลต้นฉบับ และใช้งานได้ทั้งจอคอม แท็บเล็ต และมือถือ
